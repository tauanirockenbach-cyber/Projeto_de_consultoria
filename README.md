# Projeto_de_consultoria
A "Metalúrgica YZ" enfrenta altos índices de acidentes de trabalho, consumo ineficiente de água/energia e falhas graves no descarte de resíduos. Como consultoria de Automação e TI, sua missão é implementar sensores IoT e dashboards para transformar a fábrica em uma Indústria 4.0 segura e sustentável.
